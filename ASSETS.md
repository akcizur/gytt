# GYTT Asset Policy

Preferred sources: Quaternius for characters/animation, Kenney for vehicles/roads/city kits/props, Poly Haven for materials/HDRI/detail.

Every production asset requires source, author, license, URL and modification status.

Allowed: CC0, public domain, MIT, Apache-2.0 and other explicitly compatible licenses.

Forbidden: ripped game assets, unclear licenses and AI-generated assets.

Production prefers vendored local assets. Remote assets are development-only fallbacks.
