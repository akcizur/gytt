# MAVON DISTRICT

A ground-up GTA-like browser game foundation built for GitHub Pages.

## Stack
Three.js, Rapier 3D, MavonEngine Core, Vite, desktop/mobile input.

## Included
Third-person player, sprint/jump, procedural city blocks, drivable vehicle, enter/exit, traffic simulation, mission HUD, responsive touch controls, GitHub Pages workflow.

## Run
npm install
npm run dev

## Build
npm run build

The architecture is intentionally clean so character animation, world streaming, NPC AI, traffic, missions, combat, audio and asset packs can be added without replacing the core.
