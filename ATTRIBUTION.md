# Mavon District asset provenance

Third-party visual assets are selected from free CC0 sources.

- Quaternius / UMRAM-Bilkent: rigged human.glb, derived from a Quaternius CC0 character. https://github.com/UMRAM-Bilkent/supine-human-model
- Kenney City Kit Suburban: CC0. https://kenney.nl/assets/city-kit-suburban
- Kenney City Kit Roads: CC0. https://kenney.nl/assets/city-kit-roads
- Kenney Nature Kit: CC0. https://kenney.nl/assets/nature-kit
- Poly Haven: CC0 HDRIs, textures and models. https://polyhaven.com/

Runtime assets have procedural fallbacks so the core game remains playable if a remote host is unavailable.
