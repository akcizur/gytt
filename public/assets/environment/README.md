# GYTT showcase environment assets

Expected production GLB files:

- `house.glb` — realistic exterior house model
- `shed.glb` — realistic garden shed model

The runtime loads these files through `AssetManager`. If either file is unavailable, the procedural showcase geometry remains active, so the game still boots.

Recommended source: CC0/public-domain assets only. Poly Haven publishes its 3D assets under CC0 and documents a photorealistic, game-ready workflow.
